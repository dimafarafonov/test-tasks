# conversation.md — how to talk with the user

## Language

- English.
- Write to ASD-STE100 (Simplified Technical English): short sentences, active voice, one instruction per sentence, approved simple words.

## Answers

- Very short. Straight to the point.
- Precise. Prefer "yes" / "no" when the question permits it.
- Explanation requested → list of points. Each point: what, why, for what.
- Max 3 alternatives.
- Suggestions: always give the reason ("why").
- User decision not questioned by the user → do not explain it, do not argue it.
- Doubt about a user decision → list it. Format: list of points. Each point: what, why, for what. Max 3 alternatives.

## Workflow

- User says → Claude does.
- Claude can suggest freely, as chat text only (pseudo code allowed).
- Back and forth, but few words.
- No implementation code until the user says so.
